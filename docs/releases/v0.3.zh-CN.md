# Awesome-MVOD v0.3 发布与审计报告

[English](v0.3.md) | **简体中文**

构建日期：2026-08-28

发布主题：**Research Portal & Taxonomy Redesign**

v0.3 保持 42 篇论文的收录范围不变，将仓库整理为三层研究门户：首页用于发现和导航，`docs/` 用于研究决策，`data/` 继续是机器可读的唯一真实来源。原有论文、数据集变体、实验协议、evidence 和 comparability 机制均保留。

## 改造摘要

- **README：**中英文首页均按“领域定义 → 研究范围 → 导航 → 近期论文 → 数据集/基线 → 协议审计”组织；统计和列表由 registry 生成。
- **方法分类：**以八类可多标签的机制组织研究，不使用浅层/深度二分法。
- **研究地图：**加入代表论文和概念演进路线，明确不表示严格引用因果。
- **数据集：**首页只显示稳定字段，`unknown` 和论文特定变体保留在详细卡片中。
- **基线：**首页锚点必须已有 baseline evidence card，不制作跨协议排行榜。
- **发布文件：**根目录报告已归并至 `docs/releases/`。

## Before / After

改造前，新读者需先理解密集的 registry 与审计信息，才能找到研究入口。改造后，首页先回答“MVOD 是什么、有哪些设定、如何找论文/数据集/基线”，严格的审计证据下沉一层而没有被删除。

## 验证原则

书目信息已核实不代表代码可用，也不代表实验可复现。论文和官方代码没有说明的实验细节继续标为 `unknown`。CI 检查 schema、引用、生成文件新鲜度、内部链接、可比性 fixtures 和单元测试。

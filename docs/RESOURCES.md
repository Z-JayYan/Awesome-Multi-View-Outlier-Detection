# Surveys, Repositories, and Benchmark Resources

## Focused reading

- [Multi-View Outlier Detection](https://doi.org/10.1007/978-3-030-00734-8_4) — focused book chapter and historical entry point.
- [DBLP](https://dblp.org/) — preferred bibliography source for author, venue, and year checks.
- [arXiv](https://arxiv.org/) — useful for discovery and public manuscripts; verify venue separately.

## Related repositories

- [Awesome Industrial Anomaly Detection](https://github.com/Z-JayYan/awesome-industrial-anomaly-detection) — strong navigation model and a related RGB-D/3D track, but not a classical MVOD benchmark.

## Dataset sources

- [UCI Machine Learning Repository](https://archive.ics.uci.edu/) — source for several base datasets.
- [NUS-WIDE](https://lms.comp.nus.edu.sg/wp-content/uploads/2019/research/nuswide/NUS-WIDE.html) — official base dataset; MVOD subsets are variant-dependent.
- [Real-IAD](https://realiad4ad.github.io/Real-IAD/) and [MVTec 3D-AD](https://www.mvtec.com/company/research/datasets/mvtec-3d-ad) — related natural multimodal/multi-view tracks.

The machine-readable version is [data/resources.yaml](../data/resources.yaml).

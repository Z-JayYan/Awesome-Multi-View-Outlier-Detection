## Version and scope

The repository identifies the current release as `v0.3.0`. CORE is consistently presented as a complete-view task setting, while PARTIAL / INCOMPLETE and INDUSTRIAL / NATURAL remain separate tracks.

## Bilingual documentation

The English and Chinese home pages link to each other. The research landscape, dataset-variant guide, comparison guide, and this report do the same. Paper titles and schema keys remain unchanged.

## Scientific usability

The release adds a field guide, an anomaly abbreviation legend, concrete examples of dataset variants, and conservative comparison statuses. It does not add a leaderboard.

## Verification principle

Verified bibliographic details do not imply that code or a reproducible protocol is available. Missing experimental details remain `unknown`.

## Checks

Schema validation, generated-file freshness, internal links, and unit tests are run in CI.

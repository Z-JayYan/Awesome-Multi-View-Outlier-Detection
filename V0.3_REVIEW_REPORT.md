## Version and scope

The repository identifies the current release as `v0.3.0`. CORE is consistently presented as a complete-view task setting, while PARTIAL / INCOMPLETE and INDUSTRIAL / NATURAL remain separate tracks.

## Bilingual web support

GitHub readers can switch between `README.md` and `README.zh-CN.md` from the first visible line. The research landscape, dataset-variant guide, comparability guide, and this report provide reciprocal language links. Paper titles and machine-readable schema keys remain in their source language to preserve identity and API stability.

## Scientific usability

The release adds a research-evolution narrative, explicit anomaly abbreviation legend, source-dataset versus benchmark-variant examples, and conservative comparison statuses. It does not add a cross-protocol leaderboard.

## Verification principle

Bibliographic verification does not imply artifact availability or protocol reproducibility. Unknown dimensions, ratios, preprocessing, seeds, contamination, and endpoints remain unknown when primary evidence is insufficient.
